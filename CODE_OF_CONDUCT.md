# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short:

- **Be respectful.** Welcome people of every background and experience level. Disagree about ideas, not people.
- **Be constructive.** Give feedback that helps the work move forward, and accept it gracefully.
- **No harassment.** Insults, personal or political attacks, sexualised language or imagery, publishing others' private information, and unwanted attention are not tolerated, in public or in private.
- **Take responsibility.** Apologise to those affected by a mistake and learn from it.

This applies in all project spaces (issues, pull requests, discussions, chat) and when representing the project elsewhere.

## Reporting

If someone's behaviour concerns you, contact the maintainer privately on GitHub ([@alexandru-tiron](https://github.com/alexandru-tiron)). Reports are handled confidentially.

Maintainers may remove, edit or reject comments, commits, code and issues that break this code of conduct. They may also warn, temporarily ban or permanently ban contributors, depending on how serious the behaviour is and whether it is repeated, following the enforcement guidelines of the Contributor Covenant.
